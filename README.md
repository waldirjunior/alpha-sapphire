# Pokémon Alpha Sapphire — Web Three.js (TCC)

Projeto de reconstrução web em **Three.js + TypeScript** baseado nos assets e dados extraídos da ROM de Pokémon Alpha Sapphire, com documentação técnica contínua para TCC e preparação para multiplayer em salas.

## Scripts disponíveis
```bash
npm install
npm run dev     # Sobe servidor de desenvolvimento Vite
npm run test    # Executa testes unitários (Vitest)
npm run build   # Compila TypeScript e gera build de produção
```
